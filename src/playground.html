NSFW Detection API

This server looks at an image and tells you whether it is safe for work. Use this page to try it by hand before calling it from your app. Images are analysed in memory and never stored.

Connecting…

1Enter your API key

This server is protected. Paste the value of its API_KEY variable (on Railway: your service → Variables). It stays in this browser.

1Pick an image

Use your own pictures, including ones you expect to be flagged, to see how the model behaves on your content.

No image at hand? (a simple drawn landscape, expect “Safe”).

Result

Call it from your code

The same request this page sends. Replace photo.jpg with a file on your machine. On Windows PowerShell, type curl.exe instead of curl.


    
Response fields: nsfw (true/false), score, predictions.
